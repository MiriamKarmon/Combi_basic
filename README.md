# קומבי-קוויז 🧁 — משחק חידון קומבינטוריקה לכיתה

משחק אמריקאיות חי בסגנון Kahoot, בעברית, RTL, לתלמידות תיכון.

## מה יש בפנים
- 5 שלבים, 20 שאלות בכל שלב (100 שאלות), נוסחה קומבינטורית אחרת בכל שלב:
  1. עקרון החיבור והכפל
  2. עם חזרה, סדר חשוב — n^k
  3. בלי חזרה, סדר לא חשוב — C(n,k)
  4. עם חזרה, סדר לא חשוב — C(n+k-1,k)
  5. בלי חזרה, סדר חשוב — P(n,k) ועצרת
- לפני כל שלב מופעל **סרטון הסבר מונפש** (MP4 בתיקיית videos/) שמסביר גם מתי משתמשים בנוסחה.
- 30 שניות לשאלה; תשובה נכונה מהירה מקבלת יותר נקודות (עד 1000).
- בסוף כל שלב מוצגת מנצחת השלב, ובסוף המשחק טבלת המנצחות.
- המנחה פותחת חדר עם קוד, התלמידות נכנסות מהטלפון עם הקוד ובוחרות שם.

## איך מפעילים
1. מעלים את כל הקבצים בתיקייה הזו (כולל תיקיית videos/) לריפו ב-GitHub ומפעילים GitHub Pages.
2. המנחה נכנסת לקישור, לוחצת "אני המנחה", ומקרינה את המסך.
3. התלמידות נכנסות לאותו קישור בטלפון, מקלידות את קוד החדר ובוחרות שם.

## אבטחה ופרטיות
הסנכרון עובר דרך שירות MQTT ציבורי חינמי (broker.emqx.io של EMQX), בלי חשבון ובלי תשלום.
מעליו מובנית במשחק שכבת הגנה מקצה לקצה:
- כל ההודעות מוצפנות ב-AES-GCM-256 עם מפתח שמחושב מקוד החדר - מי שמאזין לשירות רואה רק ג'יבריש.
- הודעות המנחה חתומות במפתח ייחודי שנוצר לכל חדר - שחקנית אחרת לא יכולה להתחזות למנחה.
- קוד החדר (9 תווים) הוא הסיסמה לחדר; אל תפרסמו אותו מחוץ לכיתה.
- הניקוד מחושב רק במסך המנחה, והשאלות נשלחות לשחקניות בלי התשובה הנכונה.
- מסך המנחה חייב להישאר פתוח כל המשחק (הוא "המוח" של המשחק).
שירות ה-MQTT עצמו מיועד לפרוטוטייפים ומשחקים; אין בו שמירת מידע מהמשחק.
